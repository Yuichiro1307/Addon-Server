# Addon-Server
SuperTuxKart 0.8.1 is an outdated version; therefore, it cannot download content by connecting directly to the STK online add-on server. To address this, we have provided this resource. (Note: This repository is designed for the WASM edition. Please be aware that it will not work with most native versions.)
## How to add an add-on
The SuperTuxKart 0.8.1 WASM Addon-Server
If you would like to add an add-on compatible with SuperTuxKart 0.8.1 and have the necessary files, please submit a pull request containing the appropriate folder structure for that add-on. We will incorporate it promptly.
If you are unable to download add-ons, try enabling the "Allow STK to connect to the network" setting within SuperTuxKart.
